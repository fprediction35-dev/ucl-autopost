YouTube bağlantısını yenile

  1. Google Cloud Console'da Credentials sayfasındaki OAuth istemcinin Client ID değerini kopyala ve buraya yapıştır:
  2. Google ile giriş yap
    Hesabını seç, kanal listesi çıkınca The Best Guessing Game kanalını seç (Daria's Travels değil), "doğrulanmamış uygulama" uyarısında Gelişmiş → Devam de, izinleri onayla.
  3. Sonunda tarayıcı "bu siteye ulaşılamıyor" diyecek. Bu normal. Adres çubuğundaki adresin tamamını kopyala (localhost:8765/?code=... ile başlar).
  4. GitHub'da Actions → Connect YouTube → Run workflow kutusuna yapıştırıp çalıştır. Kod birkaç dakika içinde geçersiz olur, hemen yap.
