Privacy Policy

Last updated: 2 November 2026

This policy covers "ucl-autopost", the posting tool behind Best Guessing Game, and this website.

Who uses the tool

The tool is used only by the owner of the Best Guessing Game accounts to publish videos to those accounts. It has no other users.

What data the tool handles

  • Access tokens issued by YouTube (Google), Instagram (Meta), TikTok and X when the owner connects their own account. They are stored encrypted as GitHub Actions secrets and used only to upload videos and read the posting status.
  • Basic account information returned by those platforms (such as account ID and username), used only to post to the correct account.

The tool does not collect, store or sell data about viewers or any other person. This website uses no cookies, analytics or tracking.

Sharing

Data is not shared with anyone. Videos and captions are sent only to the platform they are published on.

Deleting data

The owner can revoke the tool's access at any time from each platform's account settings, which invalidates the stored tokens. To ask a question or request deletion, email fprediction35@gmail.com.
